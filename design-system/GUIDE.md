# 多保命 Design System 使用指南

社群圖畫布：**1080 × 1350 px**（IG / Threads 4:5）。

## 資料夾
| 檔案 | 用途 |
|---|---|
| `tokens.css` | 色票、字級、圓角、陰影的單一來源（網站也可 `@import`） |
| `templates.html` | 8 款範本（封面、說明、數字、截圖、比較、步驟、功能卡、CTA） |
| `bg.html` | 背景素材來源 |
| `export.sh` | 一鍵輸出 `out/`：`backgrounds/`、`previews/`、`canva/` |
| `out/backgrounds/` | 背景 PNG（2160×2700，@2x）：`bg-full` 完整背景、`bg-gradient-waves` 漸層+青海波、`bg-gradient` 純漸層、`bg-waves-transparent` / `bg-cloud-transparent` 透明圖層 |
| `out/canva/*.pdf` | 每個範本一頁 PDF，文字可編輯 |

改了範本或 tokens 後，執行 `design-system/export.sh` 重新輸出。

## 色票
| 用途 | 色碼 |
|---|---|
| 標題、主要文字 `--deep` | #2C5A96 |
| 副標 `--deep-dark` | #1F4474 |
| 小標、頁碼、圓點 `--accent` | #6592CD |
| 邊框 `--mid` | #B6CCF0 |
| 背景 `--light` → `--paper` | #D7E1F2 → #EEF3FB |
| 金（標籤、螢光筆、重點框）`--gold` | #F8D85E（邊線 #E2B832、金上文字 #3A2A06） |
| 祥雲、青海波描邊 `--gold-deco` | #E3B04B |
| 內文 / 輔助文字 | #26262B / #6B6A64 |

規則：藍色負責結構，金色只點綴（一頁最多 1–2 處：螢光筆、一個標籤、一個重點卡）。金色背景上一律用深褐字 #3A2A06，白字不要放在金色上（對比不足）。

## 字型與字級（1080 寬畫布）
**字型：Noto Sans TC**，只用 4 種字重：400 一般、500 中等、700 粗、900 特粗。Canva、Google Fonts、網站都有，跨平台一致。

| 元素 | 字級 | 字重 | 備註 |
|---|---|---|---|
| 封面主標 | 150（兩行以上用 124） | 900 | 字距 +0.04em，行高 1.1 |
| 頁面標題 H2 | 76 | 900 | 最多兩行，行高 1.22 |
| CTA 網址 | 88 | 900 | |
| 卡片標題 H3 | 44 / 36 / 32 | 700 | |
| 副標 / 引導句 | 36 | 700 | |
| 小標 kicker | 30 | 700 | 藍 #6592CD，左側 6px 金線 |
| 內文 | 32 | 500 | 行高 1.7 |
| 條列 | 29 | 500 | 行高 1.55 |
| 卡片說明、註解 | 25 | 500 | 灰 #6B6A64 |
| 頁碼、頁尾、免責聲明 | 24–26 | 500–700 | **最小 24px**，再小手機看不清 |

原則：一頁只有 3 層字級（標題／內文／註解）；標題 ≤ 2 行，每頁重點 ≤ 3 點；重點詞用螢光筆，不要同時加粗+變色+底線。
**螢光筆**：文字下半 38% 塗金色，Canva 裡用一條 #F8D85E 的矩形放在文字後面（高度約字高 40%、置底），或直接用 Canva 的「文字醒目提示」設成 #F8D85E。

## 版面
- 左右邊距 **84px**、上 92px、頁尾 logo 距底 48px（右下，logo 圓形 44px + 「rnhighpass.com」26px）
- 卡片：白底、圓角 28、邊框 2px #B6CCF0（70%）、陰影 0 10 30 藍 10%
- 重點卡：金色 4px 邊框 + 金色陰影
- 標籤（pill）：圓角 999、白底、3px 藍邊、粗體；重點標籤改金底
- 截圖框：白底圓角 22、內距 22；網站截圖用瀏覽器外框（圓角 20、上方三點）
- 圖與文字間距 ≥ 24px；不要貼到邊距外

## 匯入 Canva
1. **建立畫布**：Canva → 建立設計 → 自訂尺寸 → 1080 × 1350 px。
2. **背景**：上傳 `out/backgrounds/*.png`（上傳 → 上傳檔案），拖進頁面設為背景。想自己配雲朵：用 `bg-gradient` 當底，再疊 `bg-waves-transparent` 與 `bg-cloud-transparent`（可縮放、移位）。
3. **範本**：首頁 → 建立 → **匯入檔案**，選 `out/canva/01-cover.pdf` 等。PDF 內文字會轉成可編輯文字；若字型顯示不同，選取文字改成 **Noto Sans TC**（Canva 內建）。之後把要保留的頁面複製進同一個設計，或各存成範本。
4. **Brand Kit**（需 Canva Pro）：新增色票（上表）與字型 Noto Sans TC，日後直接取色。
5. 匯入後若有不對齊處（PDF 匯入偶有位移），以 `out/previews/*.png` 為標準對照。

## 不靠 AI 做新貼文
- **網頁法**：複製 `templates.html`（或參考 social/post1/slides.html）→ 改文字 → 改 `body { --total: "08" }` 為總頁數 → `social/render.sh` 輸出 PNG。
- **Canva 法**：開範本 PDF 的頁面 → 改字 → 匯出 PNG（2x 品質 = 2160×2700）。

## 套用到網站
社群圖是 1080 寬，網站基準 16–18px，換算約 **社群字級 ÷ 5**：內文 32 → ~17px（保持 16px 以上）、H2 76 → ~30px、封面標題 150 → ~clamp(40px, 8vw, 64px)。色票與字型可直接沿用 `tokens.css`；網站 `style.css` 目前沒有金色，若要加：`--color-gold: #F8D85E; --color-gold-line: #E2B832;`。圓角網站現為 12/8，社群為 28/22，建議網站卡片逐步提高到 16–20 以與社群一致。
