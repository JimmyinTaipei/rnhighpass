傳導阻滯

傳導阻滯是「高速公路」某一段塞車或斷掉。塞在哪裡，就決定心電圖哪一段變長、哪一個波消失。建議搭配 3D 心臟一起看：電流會在阻斷的地方停住。

竇房結的問題：Sinus arrest 與 SA block

SA node 本身不放電，或放電了卻傳不出去，結果都是「一整拍 P-QRS-T 消失」。差別在停頓的長度：

竇性停止 Sinus arrest

二度 SA block（type II）

  • 口訣：Type I「縮短 → 消失」、Type II「固定 → 消失」。一度 SA block 在體表心電圖上看不出來，三度則和 sinus arrest 無法區分。
進階：竇房結症候群 Sick sinus syndrome

SA node 本身或它周邊的傳導退化（老化、纖維化、藥物、手術後），可以表現為竇性過慢、竇性停止、SA block，或是快慢症候群（tachy–brady syndrome）：一陣心房顫動等快速心律不整後，接著一段很長的停頓。有症狀者通常需要永久性節律器。

一度房室傳導阻滯

  • PR > 5 小格（0.20 秒）且固定，每個 P 後面都有 QRS。其實不是「阻斷」，只是 AV node 傳得比較慢。
  • 原因：迷走神經張力高、β-blocker、鈣離子阻斷劑、毛地黃、下壁 MI、老化。
  • 通常沒有症狀、不需治療，注意是否進展成更高度的阻滯。

二度房室傳導阻滯 常考

有些 P 波傳下去、有些傳不下去（出現「P 後面沒有 QRS」）。分成兩型，重點在掉拍前的 PR 有沒有變化：

Mobitz I（Wenckebach）

  • PR 越來越長 → 掉一個 QRS → 重新開始，一組一組重複出現（規則的不規則）。
  • 阻斷位置多在 AV node，QRS 窄。常見於下壁 MI、藥物、迷走神經張力高。
  • 通常良性、較少進展成三度；有症狀才需處理。
▶ 在 3D 心臟看 AV node 越來越累

Mobitz II

  • PR 固定不變，卻沒有預警地突然少一個 QRS。
  • 阻斷位置在 His bundle 以下（束支），QRS 常合併變寬。常見於前壁 MI。
  • 危險：可能突然進展成三度 AV block 或心搏停止，通常需要節律器。
▶ 在 3D 心臟看電流在 His 以下被擋住
進階：2:1 AV block 怎麼分型？

每兩個 P 只下傳一個時，沒有「連續兩拍」的 PR 可以比較，單看心電圖無法分辨是 Mobitz I 還是 II。線索：QRS 窄、其他時段出現 Wenckebach 現象 → 偏向 I 型（AV node）；QRS 寬、合併束支阻滯 → 偏向 II 型。確定診斷需要電生理檢查（EPS）。三個以上 P 才下傳一個（3:1、4:1）稱為高度 AV block。

三度（完全）房室傳導阻滯 危急

  • 心房的電流完全傳不到心室：P 波規則、QRS 也規則，但各跳各的（房室解離），PR 毫無規律。
  • 心室靠下方的逸搏點維持：交界區逸搏 → 窄 QRS、40–60 次/分；心室逸搏 → 寬 QRS、20–40 次/分。
  • 心房速率一定比心室快。

護理重點

  • 心輸出量下降：評估意識、血壓、有無暈厥（Adams–Stokes 發作）。
  • 準備經皮節律器（transcutaneous pacing），依醫囑安排暫時性或永久性節律器；阻斷在 His 以下時 Atropine 往往無效。

束支傳導阻滯 RBBB、LBBB

束支斷掉之後，那一側心室只能等另一側的電流「穿過心肌細胞」慢慢傳過來。心肌細胞間的傳導比 Purkinje 慢很多，所以 QRS 變寬（≥ 3 小格，0.12 秒），而且兩側心室不同步，QRS 會出現兩個尖峰。

右束支傳導阻滯 RBBB

  • QRS ≥ 3 小格；V1、V2 呈 RSR′（M 型、兔耳朵）；I、aVL、V5、V6 有寬鈍的 S 波（slurred S）。
  • V1–V3 常見 T 波倒置（ST-T change），屬於繼發性改變。
  • 為什麼：左心室照常先去極化（前面的 R），右心室晚一步被活化，所以 V1 最後又多了一個向上的 R′。
  • 可見於正常人，也可見於肺栓塞、右心室肥厚、心房中膈缺損、缺血性心臟病。
▶ 在 3D 心臟看右心室晚一步

左束支傳導阻滯 LBBB

  • QRS ≥ 3 小格；V1 寬而深的 S 波；I、aVL、V5、V6 寬、有缺口（M 型）的 R 波，且沒有中膈 q 波。
  • 左側導程 ST 下降、T 波倒置（與 QRS 方向相反）。
  • 為什麼：中膈改成由右往左去極化（左側導程的小 q 消失），左心室最後才慢慢被活化，所以左側導程是一個寬大的 R。
  • LBBB 幾乎都代表有心臟病（高血壓、冠心病、心肌病變、主動脈瓣狹窄）。胸痛合併新出現的 LBBB，要當成 STEMI 處理。
▶ 在 3D 心臟看左心室晚一步
進階：LBBB 合併 MI（Sgarbossa criteria）

LBBB 本身就會造成 ST-T 改變，使 MI 難以判讀。下列任一項支持合併急性 MI：

  • QRS 正向的導程出現同向 ST 上升 ≥ 1 mm（5 分）。
  • V1–V3 出現同向 ST 下降 ≥ 1 mm（3 分）。
  • QRS 負向的導程出現過度的反向 ST 上升（≥ 5 mm，或修正版：ST/S 比值 ≥ 25%）。

分支阻滯（半阻滯）

左束支再分成前分支與後分支。只斷其中一支時，QRS 寬度正常，但電流的主要方向改變 → 表現為電軸偏移。

預激症候群：WPW 與 LGL

WPW 症候群（Wolff–Parkinson–White）

  • 心房與心室之間多了一條旁路（Kent bundle），電流不經過 AV node 的延遲，提早進入心室。
  • 三大特徵：PR 短（< 3 小格）、delta wave（QRS 起始處變鈍的斜坡）、QRS 變寬；常合併繼發性 ST-T 改變。
  • 為什麼有 delta wave：旁路先活化一小塊心室，只能在心肌間慢慢傳（斜坡）；接著正常經 AV node 下來的電流趕到，後半段才又快又尖。
  • 旁路加上 AV node 可以形成迴圈 → 容易發作 AVRT（見「心律不整」PSVT 進階）。
▶ 在 3D 心臟看 Kent bundle 抄捷徑
進階：WPW 合併心房顫動為什麼危險

AV node 平常會擋掉大部分亂流，但旁路沒有這個保護。AF 時心房的高頻電流可經旁路直接衝進心室，心跳可達 250–300 次/分，並可能惡化成 VF。此時不能給會阻斷 AV node 的藥物（Adenosine、β-blocker、鈣離子阻斷劑、毛地黃），反而會讓更多電流改走旁路；不穩定時需電擊整流。

LGL 症候群（Lown–Ganong–Levine）

  • 旁路（James fiber）繞過 AV node 後接到 His bundle，之後仍走正常傳導系統 → 只有 PR 短，QRS 正常、沒有 delta wave。
