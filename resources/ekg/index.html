心電圖教學

心電圖其實就是「電流在心臟裡怎麼走」的紀錄。先在 3D 心臟上把速度放慢，看電流從 SA node 一路走到心室，對照下方心電圖是哪一個波，再去讀各章節會容易很多。

怎麼使用

  • 旋轉、縮放：拖曳心臟可以旋轉，滾輪或兩指縮放；右上角可以切換正面、左側、下方視角。
  • 放慢速度：預設是 0.25 倍速。想看清楚電流在 AV node 停頓、或束支阻滯時哪一側比較慢，可以切到 0.1×。
  • 逐段前進：按「下一段」會暫停，並跳到下一個波段（P → PR → QRS → ST → T），下方的說明會告訴你這時候電流在哪裡。
  • 顏色：黃白色是正在前進的去極化波前、紅色是已經去極化（正在收縮）、藍色是正在再極化，傳導系統被電流通過時會亮起來。
  • 導程：切換 II、V1、V6，並打開「導程方向」，可以對照「電流朝向正極 → 正波」的原則，看為什麼 RBBB 在 V1 會出現兔耳朵。
  • 心臟是為了教學簡化過的示意模型，形狀與比例不是真實解剖；波形也是示意圖，真實的心電圖請看各章節中的 12 導程範例。
