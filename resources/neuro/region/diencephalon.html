Diencephalon

視丘、下視丘、上視丘、視丘下部與內囊。視丘的每一個核都畫成 3D，點一個核就會畫出它的傳入與傳出（到哪一區皮質、經內囊哪一段）；切面從腦幹一路往上，變成大腦的水平切面。可以模擬視丘症候群、內囊梗塞、偏身投擲症、Korsakoff 症候群與顱咽管瘤。

每一段都有視丘皮質與皮質視丘纖維（Barr p.247, 253–255；Haines p.220）。後肢的小梗塞就能造成對側偏癱（內囊梗塞（後肢與膝部））。

下視丘各核

區核區帶功能
視交叉區（前）視前區內側區終板後方、下視丘最前端（嚴格說屬於端腦）。偵測血液溫度、啟動散熱；腹外側視前核在熟睡時最活躍
視交叉上核內側區生理時鐘，調節晝夜節律與松果腺的褪黑激素分泌
視上核外側區視神經徑背外側的大細胞神經分泌核，主要製造抗利尿激素（血管加壓素），經下視丘垂體徑送到垂體後葉
室旁核室周區大細胞部製造催產素（也有血管加壓素）送到垂體後葉；小細胞部發出下視丘脊髓徑，控制自主神經
下視丘前核內側區散熱中樞的一部分；刺激前下視丘引起副交感（膽鹼性）反應
結節區（中）腹內側核內側區飽食中樞
下視丘背內側核內側區結節區、腹內側核上方的核，和進食、喝水、體重有關
弓狀核室周區把釋放激素與抑制激素送進垂體門脈，控制垂體前葉
下視丘外側區外側區沒有明確的核，細胞散在內側前腦束的縱行纖維之間。進食中樞；orexin 神經元維持清醒
乳頭區（後）下視丘後核內側區保溫、產熱（寒冷時血管收縮、發抖）；附近的結節乳頭核是腦中唯一的組織胺神經元，維持清醒
乳頭體內側區接收穹窿（海馬），經乳頭視丘徑投射到視丘前核——Papez 迴路的一站

由前往後分視交叉區、結節區、乳頭區；以穹窿為界分內側區與外側區（Barr p.188；Haines p.220–221）。前下視丘刺激 → 副交感反應，後、外側 → 交感反應（Barr p.190）。

間腦的病灶

  • 視丘症候群（Dejerine–Roussy）
  • 內囊梗塞（後肢與膝部）
  • 偏身投擲症（視丘下核）
  • Wernicke–Korsakoff 症候群（乳頭體、背內側核）
  • 顱咽管瘤（鞍上腫瘤）

也和間腦有關：Parinaud 症候群（中腦背側症候群）（松果腺腫瘤壓迫頂蓋）、視神經徑病灶（前脈絡膜動脈）、下視丘脊髓徑受損的 Horner 症候群。

重點

  • 視丘除了網狀核以外，每一個核都投射到皮質、也都接收同一區皮質的回饋；各核之間沒有直接連結（Barr p.178）。
  • 嗅覺以外的所有感覺都在視丘換站：身體 VPL、臉 VPM、視覺 LGN、聽覺 MGN（Barr p.182；共筆）。
  • 運動視丘：小腦 → VL 後部 → 中央前回；蒼白球 → VA、VL 前部 → 運動前區、輔助運動區（Barr p.181–182）。
  • 邊緣視丘：乳頭體 → 前核 → 扣帶迴；杏仁核、內嗅皮質 → 背內側核 → 前額葉（Barr p.183）。
  • 內囊：前肢（尾狀核與豆狀核之間）、膝部、後肢（視丘與豆狀核之間）、後豆狀部、豆狀核下部；運動纖維集中在後肢，小梗塞就能偏癱（Barr p.253–256）。
  • 下視丘：自主神經（前 → 副交感、後 → 交感）、體溫、飲食、晝夜節律，並經神經分泌控制垂體（Barr p.188–197）。
