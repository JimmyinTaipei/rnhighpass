傳導路徑・前庭 ★★★

前庭眼反射（水平） VOR

Horizontal vestibulo-ocular reflex

頭向右轉 → 右外側半規管興奮 → 右前庭神經核 → 經 MLF 到對側（左）外旋神經核 →（1）左外旋神經 → 左外直肌；（2）核間神經元交叉回右側內側縱束 → 右動眼神經核 → 右內直肌。兩眼一起往左轉，轉的角度和頭相同、方向相反，讓視線保持不動。

神經元鏈

  1. 前庭神經節（第 1 級）

    細胞本體
    前庭神經節（Scarpa 神經節）
    路線
    周邊突接外側半規管壺腹嵴；中樞突經前庭耳蝸神經的前庭部分進腦幹。
    終止於
    同側前庭神經核（內側核為主）

  2. 前庭神經核

    細胞本體
    前庭神經核
    路線
    興奮性纖維交叉，經 MLF 到對側外旋神經核；另有纖維到同側動眼神經核的內直肌次核，以及抑制同側外旋神經核（Haines p.330–331）。
    終止於
    對側外旋神經核（運動神經元與核間神經元）

  3. 外旋神經

    細胞本體
    外旋神經核的運動神經元
    路線
    經外旋神經出去。
    終止於
    同側（頭轉動方向的對側）外直肌

  4. 核間神經元（MLF）

    細胞本體
    外旋神經核的核間神經元
    路線
    立刻交叉，在內側縱束上行。
    終止於
    動眼神經核（內直肌次核）

  5. 動眼神經

    細胞本體
    動眼神經核
    路線
    經動眼神經出去。
    終止於
    內直肌

在哪裡交叉

交叉兩次：前庭核 → 對側外旋神經核，核間神經元再交叉回來，所以最後是轉頭那一側的內直肌與對側的外直肌一起收縮（Haines p.330–331）。（橋腦下段（顏面丘））

在各切面的位置

點切面可以看那一節所有的路徑。

排列

  • 三對半規管各管一個平面：外側（水平）半規管 → 水平眼動（外直肌、內直肌）；前、後半規管 → 垂直與旋轉眼動（上、下直肌與斜肌，經滑車、動眼神經核）（Haines p.330–331）。

臨床

  • 眼球震顫：慢相由前庭核驅動、快相是把眼睛拉回來的掃視；方向以快相命名（Barr p.339–340；Haines p.331）。
  • 冷熱水試驗（清醒的人）：冷水 → 快相往對側、溫水 → 快相往同側（COWS）（Haines p.331；HY p.106）。
  • 昏迷病人（沒有快相）：冷水 → 兩眼慢慢偏向灌冷水那一側；兩側 MLF 斷掉時只有外展的那一眼會動；前庭核受損則完全不動（Barr p.340；HY p.106–107）。
  • 娃娃眼現象：昏迷病人轉頭時兩眼往反方向動，表示前庭器、前庭神經與核、MLF、外旋與動眼神經核都完整；消失是腦幹死亡的徵象之一（Barr p.340）。
  • Head thrust test：盯著目標、快速轉頭，反射不好的一側眼睛會落後、再補一個掃視（共筆）。
  • 國考：連接前庭神經核與眼動神經核的是內側縱束（共筆，國考 1091、1121）。

相關病灶：核間性眼肌麻痺（MLF 症候群）、迷路動脈阻塞（內耳梗塞）
