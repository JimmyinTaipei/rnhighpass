傳導路徑名稱對照表

同一條路徑在不同課本、共筆裡常常有不同的名字。這張表把正式名稱、常見別名、起點、終點與交叉位置放在一起；點名稱可以看完整的神經元鏈與 3D 路線。

顏色

同一類路徑用同一個色系、不同深淺；3D、切面與各頁的圖例都用同一套顏色。

  • 體感覺（上行到皮質）
  • 皮質下行
  • 腦幹下行
  • 前庭與眼動
  • 脊髓小腦
  • 小腦迴路
  • 下視丘與邊緣
  • 聽覺
  • 視覺與瞳孔
  • 基底核迴路

Posterior column–medial lemniscus pathway		 posterior column–medial lemniscus (PCML)、dorsal column–medial lemniscus (DCML)、posterior column system、dorsal column system、dorsomedial system、medial lemniscus system 背根神經節（大型、有厚髓鞘的 Aβ、Aα 纖維） → 初級體感覺皮質（中央後回）（中央後回 areas 3、1、2） 延髓下段的感覺交叉（內弓狀纖維）（內弓狀纖維） ★★★
前外側系統（脊髓視丘徑）
Anterolateral system (spinothalamic tract)		 spinothalamic tract (STT)、lateral spinothalamic tract (LSTT)、anterior spinothalamic tract (ASTT)、ventral spinothalamic tract、外側脊髓視丘徑、前脊髓視丘徑 背根神經節（小型，Aδ 與 C 纖維） → 初級體感覺皮質（中央後回）（另有到 SII、腦島、扣帶迴） 在脊髓的每一節，經白質前連合交叉，通常在進入點上方 1–3 節內完成 ★★★
後脊髓小腦徑
Posterior (dorsal) spinocerebellar tract		 dorsal spinocerebellar tract、posterior spinocerebellar tract、背側脊髓小腦徑、Flechsig tract 背根神經節（Ia、Ib、II 纖維） → 同側小腦（蚓部與蚓旁的脊髓小腦） 不交叉，從頭到尾都在同側 ★★★
前脊髓小腦徑
Anterior (ventral) spinocerebellar tract		 ventral spinocerebellar tract、anterior spinocerebellar tract、腹側脊髓小腦徑、Gowers tract 背根神經節 → 與起源同側的小腦皮質 交叉兩次：在腰薦髓經白質前連合交叉一次，進入小腦後又交叉回來，所以淨效果是同側（Barr p.74；Haines p.256） ★★☆
楔小腦徑
Cuneocerebellar tract		 cuneocerebellar tract、楔小腦束、lateral cuneate nucleus、accessory cuneate nucleus、external cuneate nucleus、外側楔束核 背根神經節（C2–T4） → 同側小腦 不交叉 ★★☆
頭側脊髓小腦徑
Rostral spinocerebellar tract		 rostral spinocerebellar tract、嘴側脊髓小腦徑 背根神經節 → 同側小腦 不交叉 ★☆☆

下行（運動）

路徑其他名稱第 1 級 → 終點交叉常考
外側皮質脊髓徑
Lateral corticospinal tract		 corticospinal tract (CST)、pyramidal tract、crossed corticospinal tract、皮質脊髓徑、皮質脊髓束、錐體徑 大腦皮質第五層的錐體細胞：約 60% 來自額葉（初級運動皮質（中央前回）、運動前區、輔助運動區），約 40% 來自頂葉（Haines p.361） → 骨骼肌 延髓與脊髓交界的錐體交叉（運動交叉）（運動交叉），約 85–90% 的纖維在這裡交叉（Haines p.365；Barr p.343） ★★★
前皮質脊髓徑
Anterior (ventral) corticospinal tract		 ventral corticospinal tract、anterior corticospinal tract、uncrossed corticospinal tract、direct pyramidal tract、腹側皮質脊髓徑、column of Türck 大腦皮質（與外側皮質脊髓徑相同） → 軀幹、近端肌肉 不在錐體交叉；多數纖維到了終止的節段才經白質前連合交叉（Barr p.75；High-Yield） ★★☆
紅核脊髓徑
Rubrospinal tract		 rubrospinal tract、紅核脊髓束、red nucleus 紅核（大細胞部） → 上肢屈肌 中腦的腹側（前）被蓋交叉（Haines p.353；Noback） ★★★
外側前庭脊髓徑
Lateral vestibulospinal tract		 vestibulospinal tract、lateral vestibulospinal tract、前庭脊髓徑、Deiters nucleus 外側前庭核（Deiters 核） → 軀幹與肢體伸肌 不交叉 ★★★
內側前庭脊髓徑
Medial vestibulospinal tract		 medial vestibulospinal tract、descending MLF、medial longitudinal fasciculus (MLF)、內側縱束 內側前庭核 → 頸部肌肉 雙側投射，以同側為主 ★★☆
頂蓋脊髓徑
Tectospinal tract		 tectospinal tract、四疊體脊髓徑、superior colliculus 上丘 → 頸部肌肉 中腦的背側（後）被蓋交叉 ★☆☆
橋腦網狀脊髓徑（內側網狀脊髓徑）
Pontine (medial) reticulospinal tract		 medial reticulospinal tract、pontine reticulospinal tract、pontoreticulospinal tract、reticulospinal tract、網狀脊髓徑、內側網狀脊髓徑 橋腦網狀結構 → 軸肌、近端肌 以同側為主 ★★☆
延髓網狀脊髓徑（外側網狀脊髓徑）
Medullary (lateral) reticulospinal tract		 lateral reticulospinal tract、medullary reticulospinal tract、外側網狀脊髓徑、gigantocellular reticular nucleus 延髓網狀結構（巨細胞網狀核） → 骨骼肌 雙側，以同側為主 ★★☆
下視丘脊髓徑
Hypothalamospinal tract		 hypothalamospinal fibers、descending autonomic pathway、Horner syndrome、Horner 症候群 下視丘（室旁核等） → 交感神經節 以同側為主，所以病灶造成同側 Horner 症候群 ★★☆

腦幹與腦神經

路徑其他名稱第 1 級 → 終點交叉常考
三叉神經感覺路徑（三叉丘腦徑）
Trigeminal sensory pathway (trigeminothalamic tracts)		 trigeminothalamic tract、ventral trigeminothalamic tract、anterior trigeminothalamic tract、dorsal trigeminothalamic tract、posterior trigeminothalamic tract、trigeminal lemniscus 三叉神經節（本體感覺的細胞本體例外，在三叉神經中腦核） → 初級體感覺皮質（中央後回）的臉部區（中央後回外下方） 痛溫覺的第二級纖維在延髓交叉，觸覺的在橋腦交叉（背側三叉丘腦徑例外，不交叉） ★★★
皮質延髓徑（皮質核纖維）
Corticobulbar (corticonuclear) tract		 corticobulbar tract、corticonuclear fibers、corticonuclear tract、皮質核徑、皮質延髓束、central facial palsy 中央前回外下方（臉部區）等運動皮質的錐體細胞 → 咀嚼肌、表情肌、咽喉肌、舌肌、胸鎖乳突肌與斜方肌 在各運動核的高度才交叉（或不交叉）：大多數是雙側投射；顏面神經核的下半臉部分只接受對側、舌下神經核以對側為主、到胸鎖乳突肌的以同側為主（Barr p.349；Haines p.197, 206） ★★★
水平注視路徑（PPRF–外旋神經核–MLF）
Horizontal gaze pathway (PPRF – abducens nucleus – MLF)		 medial longitudinal fasciculus (MLF)、internuclear neurons、核間神經元、paramedian pontine reticular formation (PPRF)、conjugate horizontal gaze、水平共軛注視 旁正中橋腦網狀結構（水平注視中樞）（接收對側額葉眼區的指令） → 內直肌（內收） 核間神經元的軸突在外旋神經核的高度立刻交叉，在對側 MLF 上行（Haines p.206–207） ★★★

間腦

路徑其他名稱第 1 級 → 終點交叉常考
乳頭視丘徑（Papez 迴路）
Mammillothalamic tract (Papez circuit)		 mammillothalamic tract、mamillothalamic fasciculus、bundle of Vicq d'Azyr、Papez circuit、Papez 迴路、fornix 海馬結構（主要是下托） → 同側扣帶迴（再經扣帶束回到海馬，完成 Papez 迴路） 不交叉：海馬、乳頭體、前核、扣帶迴都在同一側（Haines p.215, 447） ★★★
下視丘垂體徑
Hypothalamohypophysial tract		 hypothalamohypophysial tract、supraopticohypophysial tract、paraventriculohypophysial tract、視上垂體徑、neurohypophysis、神經垂體 視上核（血管加壓素為主）與室旁核（催產素為主） → 垂體後葉的微血管旁：荷爾蒙儲存在末端的 Herring 小體，動作電位一到就釋放進血液 不交叉；兩側的纖維在垂體柄合在一起（Barr p.194） ★★★

基底核

路徑其他名稱第 1 級 → 終點交叉常考
基底核直接路徑
Direct pathway of the basal ganglia		 direct pathway、direct loop、直接迴路、striatopallidal fibers、pallidothalamic fibers、紋狀體蒼白球纖維 運動前區、輔助運動區、初級運動與體感覺皮質 → 同側運動前區、輔助運動區 不交叉：整個迴路都在同一個半球；症狀出現在對側身體，是因為最後經皮質脊髓徑下行時才交叉（Barr p.205–209） ★★★
基底核間接路徑
Indirect pathway of the basal ganglia		 indirect pathway、indirect loop、間接迴路、subthalamic fasciculus、視丘下束、pallidosubthalamic fibers 運動與運動前區皮質 → 同側視丘 視丘腹外側核、腹前核 不交叉，整個迴路在同一側；所以單側視丘下核受損，症狀在對側身體（偏身投擲症（視丘下核））（Barr p.211） ★★★
黑質紋狀體路徑
Nigrostriatal pathway		 nigrostriatal fibers、nigrostriatal pathway、黑質紋狀體纖維、dopaminergic pathway、多巴胺路徑 黑質緻密部（多巴胺、含神經黑色素） → 同側殼核、尾狀核（D1 興奮、D2 抑制） 不交叉（Barr p.206） ★★★

小腦

路徑其他名稱第 1 級 → 終點交叉常考
皮質–橋腦–小腦路徑
Corticopontocerebellar pathway		 corticopontocerebellar pathway、corticopontine tract、pontocerebellar fibers、皮質橋腦徑、橋腦小腦纖維、cerebropontocerebellar 額葉、頂葉為主的大腦皮質（也有顳葉、枕葉） → 對側小腦外側區（小腦半球）的皮質（苔狀纖維 → 顆粒細胞） 在橋腦基底部交叉：左大腦的訊號到右小腦（Barr p.170；Haines p.409） ★★☆
橄欖小腦徑（攀緣纖維）
Olivocerebellar tract (climbing fibers)		 olivocerebellar tract、olivocerebellar fibers、climbing fibers、攀緣纖維、橄欖小腦纖維、olive-cerebellum tract 下橄欖核 → 齒狀核（抑制性，GABA） 在延髓交叉：右下橄欖核的纖維到左小腦 ★★☆
齒狀核–視丘–皮質路徑（小腦輸出）
Dentatothalamocortical pathway (cerebellar output)		 dentatothalamic tract、dentatorubrothalamic tract、cerebellothalamic fibers、齒狀核視丘徑、齒狀紅核視丘徑、superior cerebellar peduncle 外側區（小腦半球）的 Purkinje 細胞 → 小腦同側脊髓的前角（例如 C6，上肢） 交叉兩次：上小腦腳在中腦下丘高度交叉一次，皮質脊髓徑在錐體交叉再交叉一次，所以右小腦管右半身（Haines p.394, 410；Barr p.171） ★★★
前庭小腦迴路
Vestibulocerebellar circuit		 vestibulocerebellum、vestibulocerebellar fibers、juxtarestiform body、近繩狀體、cerebellovestibular fibers、corticovestibular fibers 前庭神經節（也有前庭神經核來的次級纖維） → 同側前庭神經核（抑制性） 不交叉：前庭神經、前庭小腦、前庭神經核都在同側（Barr p.168；Haines p.405） ★★☆

視覺與瞳孔

路徑其他名稱第 1 級 → 終點交叉常考
視覺路徑（視網膜–外側膝狀核–視覺皮質）
Visual pathway (retino-geniculo-calcarine)		 visual pathway、retinogeniculocalcarine pathway、retinogeniculate projection、geniculocalcarine tract、geniculostriate pathway、視覺傳導路徑 視網膜的節細胞（前面還有感光細胞、雙極細胞，都在視網膜裡） → 同側初級視覺皮質（距狀溝上唇 = 下半視野、下唇 = 上半視野） 只在視交叉部分交叉：鼻側視網膜（看顳側視野）的纖維交叉，顳側視網膜的不交叉 ★★★
瞳孔光反射
Pupillary light reflex		 pupillary light reflex、light reflex、對光反射、瞳孔對光反射、direct light reflex、consensual light reflex 視網膜的節細胞（包括本身會感光、含 melanopsin 的節細胞） → 瞳孔括約肌（多數節後纖維其實到睫狀肌） 兩個地方：視交叉（鼻側的纖維）與後連合（頂蓋前核 → 對側 EW 核） ★★★

聽覺與前庭

路徑其他名稱第 1 級 → 終點交叉常考
聽覺路徑
Auditory pathway		 auditory pathway、ascending auditory pathway、聽覺傳導路徑、central auditory pathway、trapezoid body、斜方體 螺旋神經節（雙極神經元） → 同側初級聽覺皮質（顳橫回）（顳橫回，Brodmann 41、42） 交叉很多次、而且不完全：背側聽紋與斜方體在橋腦下段交叉，兩側下丘之間還有連合纖維，每一側外側蹄系都帶著兩耳的訊息（以對側耳為主） ★★★
前庭眼反射（水平）
Horizontal vestibulo-ocular reflex		 vestibulo-ocular reflex (VOR)、vestibuloocular reflex、前庭眼球反射、doll's eyes、oculocephalic reflex、娃娃眼 前庭神經節（Scarpa 神經節） → 內直肌 交叉兩次：前庭核 → 對側外旋神經核，核間神經元再交叉回來，所以最後是轉頭那一側的內直肌與對側的外直肌一起收縮（Haines p.330–331） ★★★
前庭–視丘–皮質路徑
Vestibulothalamocortical pathway		 vestibulothalamic tract、vestibulothalamocortical pathway、vestibular cortex、前庭皮質、vestibular cortical field 前庭神經節（Scarpa 神經節） → 前庭皮質（頂葉島葉前庭皮質）、area 2v、3a、頂葉後部 以對側為主，但兩側都有（Haines p.332） ★☆☆
